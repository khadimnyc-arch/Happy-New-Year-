# Happy New Year Ball Drop

An interactive Processing application written in Java that simulates a New Year's Eve countdown animation.

## Features

* **Ball Drop & Countdown:** Displays a colorful ball dropping along the left side while ticking down from "3", "2", to "1".
* **Celebration Screen:** Once the ball reaches the bottom, the application switches to a "HAPPY NEW YEAR" banner accompanied by flashing confetti.

## How to Run

1. Clone or download this repository.
2. Open the project in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Ensure the **Processing core library** (`core.jar`) is added to your project dependencies/classpath.
4. Run `Main.java`.

## Requirements

* Java JDK 8 or higher
* Processing 3/4 `core.jar` library
